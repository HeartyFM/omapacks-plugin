# OmaPacks 0.4.2 · corrección de Steam

1. Instala este plugin mediante Add Plugin o actualiza su copia existente.
2. Acepta instalar/actualizar el gestor 0.4.2; conserva origen y confianza.
3. Abre Install/Update → Configuración compartida y selecciona la release deseada.
4. Revisa el plan: para Radeon pueden faltar vulkan-radeon, lib32-vulkan-radeon y lib32-mesa.
5. Confirma y comprueba el resultado. Los juegos no se abren al instalarlos.

Ante un error, comparte el diagnóstico y `omapacks support-report`. No se habilita Secure Boot ni se cambian kernel, arranque o configuración de GPU.
